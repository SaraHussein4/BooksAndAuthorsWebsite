# 📚 Book & Author Website

This project is a responsive **Book and Author Website** built to showcase books, their authors, and latest releases. The website includes multiple sections and provides users with easy navigation and engaging content related to literature and publishing.

## 🌐 Website Pages

The site contains **five main pages**, each with a specific purpose:

1. **Home**
   - A brief overview of the website.
   - Highlights featured books, authors, and the latest book releases.
   - Quick links to other pages.

2. **Books**
   - Displays a collection of available books.
   - Each book includes a title, cover image, and description.

3. **Authors**
   - Lists authors featured on the site.
   - Includes author bios and description

4. **Latest Book**
   - Focuses on the most recently published or featured book.

5. **Contact Us**
   - A contact form for visitors to get in touch.
   - Includes email and/or social media contact options.

## ✨ Features

- Responsive design using modern HTML, CSS (and optionally Bootstrap)
- Clean navigation for easy access to all pages
- Book and author showcase with descriptions and images
- Focus on the latest publication with a dedicated section
- Contact form for user interaction
